# Journal Manager

## About the Project

Journal Manager is a simple Python program that allows users to
create and manage their personal journal entries.

The program stores journal entries in a text file called
`journal.txt`. Users can add new entries, view saved entries,
search for a particular keyword or date, and delete all entries.

This project is mainly created to practice **file handling,
exception handling and basic Object-Oriented Programming (OOP)**
in Python.

---

## Features

- Add a new journal entry
- Automatically add date and time to each entry
- View all saved entries
- Search entries using a keyword or date
- Delete all journal entries
- Ask for confirmation before deleting
- Handle missing files
- Handle file creation errors
- Handle permission errors
- Simple menu-driven interface
